# Examples

Two design systems generated by Kaava, each from a brand color and a style. The names are Finnish, like Kaava itself.

| Folder | Name means | Brand color | Style |
|---|---|---|---|
| [`ahtaaja/`](ahtaaja) | stevedore | `#4f46e5` | friendly |
| [`hinaaja/`](hinaaja) | tugboat | `#ffd400` | playful |

Each folder is exactly what Kaava writes into a project: `kaava.json` (the brief and every token) and `kaava/` with all output formats, including [`DESIGN.md`](ahtaaja/kaava/DESIGN.md) and a `preview.html` you can open in a browser.

Everything here is generated. Do not edit it by hand: change the briefs in [`scripts/examples.mjs`](../scripts/examples.mjs) and run `npm run examples`. A test fails when these files no longer match what the engine produces.
